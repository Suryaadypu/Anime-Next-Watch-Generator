# Anime Next Watch Generator

## Project Overview

Anime Next Watch Generator is a web application designed to help users decide what anime to watch next. The app fetches real-time data from a public API and presents a list of trending anime. Users can explore anime based on popularity, ratings, and genres, and view a short synopsis before deciding what to watch.

This project demonstrates the use of JavaScript for API integration, dynamic content rendering, and basic UI development using HTML and CSS.

## Objective

The goal of this project is to build a responsive web application that:

* Fetches real-time anime data from a public API
* Displays the data dynamically on a webpage
* Allows users to filter and explore anime content
* Provides a clean and user-friendly interface

## API Used

This project uses the Jikan API, which is an unofficial MyAnimeList API.

API Documentation:
https://docs.api.jikan.moe

## Features (Planned and Implemented till Milestone 2)

* Fetch and display trending/top anime
* Dynamic rendering of anime cards (title, image, rating)
* Expandable section to view synopsis
* Basic genre-based filtering (planned for further enhancement)
* Loading state while fetching data
* Responsive design for mobile, tablet, and desktop

## Technologies Used

* HTML for structure
* CSS for styling and layout
* JavaScript for logic and API integration
* Fetch API for making HTTP requests

## Project Structure

* index.html: Main HTML file
* style.css: Styling for the application
* script.js: JavaScript logic including API calls and DOM manipulation

## How to Run the Project

1. Clone the repository:
   git clone <your-repository-link>

2. Navigate to the project folder:
   cd anime-next-watch-generator

3. Open the project:
   Open index.html in your browser

No additional setup or dependencies are required.
